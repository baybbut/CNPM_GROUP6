# Muses Museum – React (Vite)

    npm install
    npm run dev

Mỗi section là 1 thư mục trong src/components (JSX + CSS riêng).
- src/data/data.js            : dữ liệu (ảnh, ngày, link)
- src/i18n/i18n.js            : 15 ngôn ngữ + bản dịch
- src/context/LangContext.jsx : state ngôn ngữ, hook useLang()
- src/index.css               : biến màu, font, nút, tiêu đề dùng chung
